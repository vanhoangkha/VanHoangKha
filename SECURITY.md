# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of my projects, please report it responsibly:

1. **DO NOT** open a public issue
2. Email: khavan.work@gmail.com
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Response Time

- Initial response: Within 48 hours
- Status update: Within 7 days
- Fix timeline: Depends on severity

## Scope

This security policy applies to all public repositories under this account.

## Recognition

Security researchers who responsibly disclose vulnerabilities will be acknowledged (with permission) in the project's security advisories.
