## About Me

I am a Cloud Security Engineer working at the intersection of cloud infrastructure, security, and community enablement. I help engineers, students, and organizations adopt AWS and Zero Trust architectures with clarity and confidence.

My focus is turning complex cloud and security concepts into accessible, hands-on learning experiences — through open workshops, production-grade reference architectures, field-tested write-ups, and mentorship.

---

## Currently

- **Building**: Zero Trust reference architectures on Cloudflare One and AWS.
- **Writing**: The *Zero Trust on Cloudflare One* series at [cloudsecop.net](https://cloudsecop.net) — a 20-part deep-dive covering Access, Gateway, CASB, DLP, RBI, DEX, and SIEM integration.
- **Mentoring**: Cloud security learners through the AWS First Cloud Journey program.
- **Exploring**: AI-driven IAM policy generation, cross-cloud workload identity, and LLM-assisted security operations.

---

## What I Do

- **Cloud Security Engineering** — Designing and automating IAM workflows, least-privilege enforcement, access key rotation, permission boundaries, and end-to-end security patterns on AWS.
- **Zero Trust and SASE** — Deploying and operating Cloudflare One across Access, Gateway, CASB, DLP, Browser Isolation, Device Posture, and DEX, with a focus on real-world rollouts and false-positive tuning.
- **AWS Architecture and Cost Optimization** — Building production-ready workloads and helping teams maximize the AWS Free Tier through practical, real-world guidance.
- **Community Leadership** — Organizing large-scale technical events (1,500+ attendees) and mentoring emerging cloud engineers across Vietnam and the APAC region.
- **Open Education and Technical Writing** — Maintaining free learning paths and long-form technical deep-dives that have reached a community of 45,000+ learners.
